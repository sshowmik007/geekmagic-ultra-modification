# SmallTV Firmware Integration & Pre-Flash Safety Spec

## Goal

Define the architecture, file organization, build pipeline, and strict safety checkpoints for compiling our custom web dashboard into an ESP8266 firmware binary (`firmware.bin`) using PlatformIO, ensuring zero risk of bricking the SmallTV-Ultra.

---

## 1. Verified Hardware Pinout (GeekMagic SmallTV-Ultra)

Cross-verified from `geekmagic-tv-esp8266-master/platformio.ini` and `codelight-master/screen`:

| Signal | ESP8266 GPIO | Description |
|---|---|---|
| **TFT MOSI** | GPIO 13 (D7) | Hardware SPI data |
| **TFT SCLK** | GPIO 14 (D5) | Hardware SPI clock (40 MHz) |
| **TFT CS** | -1 | Tied permanently to GND |
| **TFT DC** | GPIO 0 (D3) | Command / Data select |
| **TFT RST** | GPIO 2 (D4) | Hardware display reset |
| **TFT BL** | GPIO 5 (D1) | Backlight PWM control (0–100%) |
| **Baud Rate** | 115200 | Serial console / Flashing |

---

## 2. Firmware Partitioning & Size Budget

* **Total Flash**: 4,194,304 bytes (4 MB)
* **Sketch Partition**: 1,048,576 bytes (1.0 MB max for OTA update)
* **OTA Reserve**: 1,048,576 bytes (1.0 MB)
* **LittleFS Partition**: ~2,097,152 bytes (2.0 MB)
* **Our Web UI Bundle**: **11,298 bytes (0.011 MB)** &rarr; Uses only **1.08%** of the sketch partition!

---

## 3. Strict Pre-Flash Verification Checklist

Before flashing any binary to the real device:

1. **Rollback Binary Verified**:
   * Stock vendor binary exists: `Ultra-V9.0.50/FW-Smalltv-Ultra-V9.0.50/Smalltv-Ultra-V9.0.50.bin`.
   * Stock MD5 verified: `a5fe50093ada3c2637225bbf306a62c3`.
2. **Binary Size Rule**:
   * Any new `firmware.bin` MUST be `<= 1,048,576 bytes`.
3. **Magic Byte Verification**:
   * Byte 0 of any ESP8266 binary must be `0xE9`.
4. **Hardware Recovery Path Confirmed**:
   * 3.3V USB-to-UART adapter on internal pads: `GND` &harr; `GND`, `TX` &harr; `RXD0`, `RX` &harr; `TXD0`.
   * Boot to flash mode: `GPIO 0` held to `GND` during power-on.
   * Command: `esptool.py --port COMx --baud 115200 write_flash 0x0 <stock_firmware.bin>`.

---

## 4. Software Architecture (`firmware/`)

When creating the firmware source:
* Keep in an isolated `firmware/` folder inside `smalltv-dashboard/`.
* `firmware/include/web_assets.h`: The gzipped dashboard generated by `npm run build:esp`.
* `firmware/src/main.cpp`: Initializes Wi-Fi, SPIFFS/LittleFS, ST7789 display, and `ESP8266WebServer`.
* `firmware/src/webserver.cpp`: Serves `DASHBOARD_HTML_GZ` on `/`, and handles `/api/status`, `/api/settings`, `/api/wifi/scan`.
